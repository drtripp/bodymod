How to Measure Biacromial Width

Straight-line shoulder bone width from acromion to acromion.

Monthly Shoulder width

Steps

  1. Find the bony point at the top outside of each shoulder.
  2. Use a rigid ruler or calipers if available.
  3. Measure straight across, not around the back.

Common Mistakes

  • Using tape circumference.
  • Including deltoid muscle width.

Tracking Note

This is a frame-width field. Small week-to-week changes usually mean landmark or tool variation.
