How to Measure Bideltoid Width

Straight-line maximum width across the deltoids.

Monthly Shoulder width

Steps

  1. Stand relaxed with arms hanging naturally.
  2. Measure the widest left-to-right shoulder span across the delts.
  3. Use a mirror or helper to keep the measuring line horizontal.

Common Mistakes

  • Flaring arms.
  • Measuring a diagonal line.

Tracking Note

Bideltoid width is useful for frame context; keep arm position identical each time.
